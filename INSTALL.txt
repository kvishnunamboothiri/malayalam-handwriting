MALAYALAM HANDWRITING - Linux app: how to install
=================================================

What it is
----------
A small always-on-top window with a tray icon. You write a word by hand or speak
(Malayalam or English) and the text is typed into whichever window you were using,
for example your browser. It never takes keyboard focus when you click it.
Recognition is done online by Google, so it needs an internet connection.

What you need
-------------
* Linux Mint 22.x (Cinnamon) or Ubuntu 24.04, logged in to an X11 session
  (Cinnamon uses X11 by default; on Wayland the pasting does not work).
* Internet access, for installing the packages and for recognition.
* A free Gemini API key for voice input (handwriting needs no key). See
  "How to get a Gemini API key" below.
* A microphone, for voice input.

How to get a Gemini API key
---------------------------
Voice input sends your speech to Google's Gemini service, which writes it out as
text. Google asks for a key so it knows who is calling. It is free for personal use
(within daily limits) and no credit card is needed.

1. Open https://aistudio.google.com/apikey in your browser.
2. Sign in with a Google account.
3. Click "Create API key". If it asks which project to use, choose "Create API key
   in new project" (or any existing project).
4. A long text starting with "AIza" appears. Click the copy button next to it.
   Keep this page's address handy: the same page lists your keys and lets you
   delete one if you ever need to.
5. Paste it into the app's Voice settings (see "First-time setup" below).

Notes
  - The button names on Google's page may change slightly over time; look for
    "Get API key" or "Create API key".
  - Treat the key like a password. Do not share it, post it online or send it in
    messages. If it leaks, delete it on the same page and create a new one.
  - The key is stored only on your computer (inside the app's settings folder).
    Each computer or phone needs the key pasted once.
  - On the free plan Google may use what you send to improve its products, so
    avoid dictating anything private. Daily limits apply; if you see "quota" or
    "high demand" errors, wait a while and try again.

Install
-------
1. Extract the archive into your home folder (or any folder you like):

       tar -xzf malayalam-handwriting.tar.gz -C ~

2. Run the installer from the extracted folder:

       ~/malayalam-handwriting/install.sh

   or, to also start the app in the tray at every login:

       ~/malayalam-handwriting/install.sh --autostart

   The installer installs any missing packages from the Linux repositories (it
   asks for your password only when something is missing), checks that Python can
   load them, then creates:
     - an entry in the applications menu ("Malayalam Handwriting")
     - an icon on your Desktop
     - with --autostart, a login entry that starts the app hidden in the tray

   The packages it uses are: python3, python3-gi, gir1.2-gtk-3.0,
   gir1.2-webkit2-4.1, python3-xlib, gstreamer1.0-plugins-good and
   gstreamer1.0-pipewire (or gstreamer1.0-pulseaudio on a PulseAudio system).
   Tray icon support (gir1.2-xapp-1.0) comes with Linux Mint.

3. Start it from the menu or the Desktop icon. Do not move the folder afterwards;
   if you do, run install.sh again from the new place.

First-time setup (once per computer)
------------------------------------
1. Click "Voice settings" at the bottom of the window.
2. Click the "API key" field and paste your Gemini key with Ctrl+V (copy it from
   the Google page first; see "How to get a Gemini API key" above).
3. Set "Microphone" to the one you actually use (for example your webcam). The
   "Automatic" choice sometimes picks a silent input.
4. Click Save. Settings are remembered.

Using it
--------
* Tray icon: left-click shows or hides the window. Middle-click starts or stops
  listening. Right-click gives "Start listening / Stop listening", "Show / hide
  window" and "Quit". So you can dictate with the window hidden: start listening
  from the tray, speak, and the text goes to the window you are using.
  The window's X button only hides it. Starting the app a second time just shows
  the copy that is already running.
  (A "hidden" window is made fully transparent, click-through and frameless, because
  the browser engine inside blocks the microphone for a truly hidden window. It
  catches no clicks.)
* Where the words go: the "Send words to" switch has two settings. "Other window"
  (default) types them into the window you were using. "This box only" keeps them
  in the app's own text box and sends nothing to other windows; the window then
  holds the keyboard so you can type there too.
* Typing in the text box: click in the box and the app takes the keyboard, so you can
  type or edit. When a spoken phrase or a handwritten word is sent to the other
  window while you are editing, the keyboard goes back to that window first.
  The box is large so longer text is easy to read and fix.
* Language: the Malayalam / English switch at the bottom decides how handwriting
  and voice are read. Set it before you write or speak.
* Voice: tap the microphone button once, speak, and pause for about a second; each
  phrase is typed into your other window. The tray icon glows red while the
  microphone is on. Tap the button again to stop (it also stops by itself after
  15 seconds of silence).
* Handwriting: write one word on the pad, then tap a suggestion, or tap Space to
  take the first one. Tapping Space twice gives a full stop.
* Buttons: the backspace button and the Enter button act on the other window.
  Cut and Copy work on the text shown in the app's own box.
* Text goes in with Ctrl+V, so it works in browsers and editors but not in
  terminals (they use Ctrl+Shift+V).

Update
------
Extract a newer archive over the old folder (or replace the folder), then run
install.sh again and restart the app (right-click the tray icon, Quit, start it).

Uninstall
---------
       ~/malayalam-handwriting/install.sh --uninstall

removes the menu entry, the Desktop icon and the login entry. Delete the folder to
remove the app itself. Saved settings are in ~/.local/share/ml-handwriting.

If something does not work
--------------------------
* Voice does nothing: watch the thin bar along the bottom of the writing pad. If it
  never moves, choose another microphone in Voice settings. A red message under the
  pad says what Google answered (for example a wrong key).
* Text does not appear in the other window: you need an X11 session, and the cursor
  must be in a text field of that window (not a terminal).
* Nonsense text appears from room noise: open Voice settings and set "Speech
  sensitivity" to "Low (noisy room)". If your quiet voice is being ignored, set it to
  "High". The thin bar along the pad shows the microphone level and a red tick marks
  how loud a voice must be to count as speech; speak so the bar passes the tick.
  The app also drops noises that are too short or have gaps, and ignores text that
  Google says is not speech. A steadier microphone helps too: in your sound settings,
  raise the input volume of the microphone and keep it away from fans and keys.
* No tray icon: make sure the "xapp-status" applet is enabled (right-click the
  panel, Applets).
* What the app heard is written to ~/.cache/ml-handwriting/debug.log (replaced on
  every start). It contains no audio, only levels and status lines.
